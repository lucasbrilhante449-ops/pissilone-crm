Regras Críticas de Desenvolvimento ### 10.1 Nunca use template literals aninhados O CRM usa template literals em muitos lugares, mas **nunca aninhe um backtick dentro de outro**. Isso causa `SyntaxError` silencioso que trava todo o JavaScript. ❌ **Errado:** ```javascript document.getElementById('x').innerHTML = ` ${items.map(i => `
${i.nome}
`).join('')} `; ``` ✅ **Correto — usar função separada ou concatenação:** ```javascript function renderItems(items) { let h = ''; items.forEach(function(i) { h += '
' + i.nome + '
'; }); return h; } document.getElementById('x').innerHTML = '
' + renderItems(items) + '
'; ``` ### 10.2 Aspas simples dentro de strings JS Nunca use `font-family:'Barlow Condensed'` dentro de uma string JavaScript com aspas simples. Use `font-family:sans-serif` ou escape como `font-family:"Barlow Condensed"`. ### 10.3 Normalização de datas Sempre use `normDate(valor)` ao ler datas do banco: ```javascript function normDate(d) { // Converte qualquer formato para YYYY-MM-DD // Aceita: YYYY-MM-DD, YYYY-MM-DDTHH:MM:SS, DD/MM/YYYY // Retorna '' se inválido } ``` ### 10.4 Salvar sempre com doSync() ```javascript // Padrão obrigatório para qualquer operação de escrita: ss('ld', 'Salvando...'); try { await apiSave(c); await doSync(); // SEMPRE chamar depois do save } catch(ex) { ss('er', 'Erro ao salvar'); } ``` ### 10.5 Deploy Após editar o `index.html`: 1. Commit no GitHub (branch main) 2. Aguardar 1-3 minutos para GitHub Pages atualizar 3. Testar com `Ctrl+Shift+R` para limpar cache --- ## 11. Funcionalidades Implementadas ### Kanban (aba Funil) - Drag & drop entre etapas - Cabeçalho fixo com nome + soma de valores em laranja - Scroll interno por coluna, footer "+ Contato" fixo - Busca de contato com destaque amarelo em tempo real - Filtro de atividade: Todos / Hoje / Agendada / Atrasada / Sem atividade - Filtro de resultado: Todos / Ganhos / Perdidos / Em aberto - Contador no header: `X cards em D2C · Y total` ### Cards do Kanban - Dot de atividade colorido (clicável → abre modal de atividade) - Badge histórico: `📊 Nx` com total de negociações - Última compra: `🛍 há X dias · Nª compra · 💰 R$Y total` + badge ⭐ VIP - Botões ✓ Ganho e ✗ Perda APENAS na etapa de negociação - Badge de resultado (ganho/perda) fora da negociação - Motivo de perda em vermelho - Botões: ✎ editar, ⧉ duplicar para Pissifã, ✕ excluir ### Modal de Ganho Ao clicar em Ganho → modal pede o valor da negociação com histórico anterior exibido. ### Modal de Contato - Nome, telefone, funil, etapa, responsável, canal, valor - Próx. atividade (data) + Descrição da atividade - Produto, observação - Histórico de negociações (data, valor, motivo de cada uma) - Total gasto acumulado - Botão "Reabrir card" quando há resultado e fora de negociação ### Insights Layout com: - SAFRA (total de cards) com ganhos/perdas/negociações - Métricas: Receita, Ticket médio, Tx. conversão, Tx. perda, Em aberto - Atividades: hoje, atrasadas, agendadas, sem atividade, checkpoints - Resultado por responsável (barras) - Tx. conversão por canal (barras coloridas) - Motivos de perda com destaque do principal - Seção Pissifã: recompras, receita recorrente, ticket médio, VIPs, frequência ### Configurar - Criar/renomear/apagar funis e etapas - Criar/remover usuários - Salvar configuração no Supabase --- ## 12. Problemas Conhecidos e Soluções ### CRM fica em "Conectando..." infinitamente **Causa:** Erro de sintaxe JavaScript (SyntaxError) que impede o carregamento. **Diagnóstico:** Abrir DevTools (F12) → Console → ver linha do erro. **Solução comum:** Template literal aninhado ou aspa simples dentro de string JS. ### Verificação rápida de saúde do arquivo ```javascript // No arquivo index.html, contar backticks no script: // Se ímpar → SyntaxError garantido // Se par → provavelmente ok ``` ### Atividade some após salvar **Causa histórica:** Havia um filtro que rejeitava timestamps ISO (`2026-06-15T03:00:00.000Z`). **Solução atual:** `normDate()` converte qualquer formato em vez de rejeitar. ### Dados com funil/etapa trocados **Causa:** Deleção de coluna na planilha Google Sheets (antes da migração). **Regra:** Nunca mais usar Google Sheets. Todos os dados estão no Supabase agora. --- ## 14. Código Fonte Atual ```html PSN CRM
